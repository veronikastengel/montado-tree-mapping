Montado Tree Mapping

Automated individual tree detection & vegetation classification — Alentejo, Portugal

The montado is Portugal's open oak woodland — a UNESCO-recognised agro-silvo-pastoral landscape where cork oak (Quercus suber) and holm oak (Quercus rotundifolia) are legally protected. This is an exploratory research project investigating how far automated remote sensing methods can go in mapping individual trees across 4 km² using only freely available data and no field visits. A key goal was to test and compare multiple unsupervised classification approaches and evaluate where each method succeeds or breaks down.

Step 1 — Tree tops
Individual tree tops detected directly from 3D LiDAR point cloud using variable-radius local maxima search
Step 2 — Crown segments
Marker-controlled watershed segmentation delineates individual crown polygons seeded from the detected tree tops
Step 3 — Landscape context
Sentinel-2 imagery classified by Random Forest into 6 landscape types: montado, olive, eucalyptus, pine, shrubland, other broadleaf
Step 4 — Tree classification
14 LiDAR + spectral features per crown classified by GMM (15 clusters) and UMAP+HDBSCAN (7 clusters) — compare both on the map
⚠ Validation gap: Cluster labels are ecologically interpreted but not field-validated. Cork oak vs holm oak could not be reliably distinguished with unsupervised methods — consistent with published remote sensing literature showing these species require hyperspectral imagery or supervised classification with ground-truth samples.
