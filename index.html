Montado Tree Mapping

Automated individual tree detection & vegetation classification — Alentejo, Portugal

This map shows ~19,000 individual trees detected automatically from laser scanning data across 4 km² of Portuguese countryside — without anyone setting foot in the field. Every coloured shape is one tree crown.

The landscape is montado — Portugal's open oak woodland, where cork oak and holm oak are legally protected. The question driving this project: can we automatically tell which tree is which, purely from remote sensing data?

1 — Find the trees
Use LiDAR data (Aircraft laser pulses) to locate each tree top
2 — Draw the crowns
Working outward from each tree top, an algorithm traces the edges of each crown
3 — Measure each tree
14 measurements per tree: height, shape, leaf density, light reflectance, ...
4 — Classify by similarity
Use different machine learning methods to group trees by how alike they are
⚠ Result: Broad types separated well — olive groves, eucalyptus, pine. But cork oak vs holm oak proved too subtle without field data to guide the algorithm.
The code and full methodology are open on GitHub.
