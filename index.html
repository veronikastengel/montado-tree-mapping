Montado Tree Mapping

Automated individual tree detection & classification — Alentejo, Portugal

The montado is Portugal's iconic open oak woodland — a protected cultural landscape where cork oak (Quercus suber) and holm oak (Quercus rotundifolia) are legally protected species. This project demonstrates what is achievable using only freely available remote sensing data and no field visits.

What this map shows

~19,000 individual tree crowns delineated across 4 km² from airborne LiDAR data, classified into vegetation types using unsupervised machine learning (GMM and UMAP+HDBSCAN). Sentinel-2 multispectral imagery provides landscape-scale context.

⚠ Validation gap: Without field-verified species identification, cluster labels are ecologically interpreted but not statistically validated. Cork oak vs holm oak could not be reliably distinguished — consistent with published remote sensing literature showing these species require hyperspectral data or supervised classification with ground truth samples.
